# SA Diplomat — Website Redesign

A modernization of [sa-diplomat.com](https://sa-diplomat.com/), refreshing the visual design while preserving the site's core structure and brand identity. The goal is an updated, current look without straying from what the original site already does well.

## About This Project

This is a client redesign project. The original site's layout and content structure remain the foundation — this redesign focuses on modernizing the visual presentation (typography, spacing, color, and overall polish) rather than a full rebuild.

## Development

Requires Node.js and npm. [Install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating) if you don't have them set up.

```sh
git clone <this-repository-url>
cd sa-diplomat-redesign
npm i
npm run dev
```
